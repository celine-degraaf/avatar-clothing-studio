# UX Principles

## Target interaction model

The app should feel closer to a simple drawing tool than to a professional 3D suite.

## Home

Primary actions:

- Create
- My Designs
- Continue Last Design

Secondary adult entry:

- Parent / Creator

## Editor navigation

Main tools should remain limited and obvious:

- Draw
- Color
- Stickers
- Layers
- Preview

Top actions:

- Back
- Save state
- Undo
- Redo
- Done / Preview

## Child-first requirements

- large touch targets
- icon + short text for important actions
- visible undo
- visible autosave state
- no critical feature available only through a hidden gesture
- destructive actions require confirmation
- plain-language error messages
- no unexpected navigation outside the app
- maximum 4–5 major controls visible at once

## Procreate-inspired research areas

Study, but do not copy:

- pinch to zoom
- quick undo
- brush size changes
- layer interactions
- color picking
- canvas-first layout
- Apple Pencil responsiveness

All essential actions still need visible alternatives for younger users.

## Figma role

Figma is used for:

- wireframes
- screen layouts
- component system
- navigation flows
- prototypes
- iPhone / iPad / Android responsive states

## Procreate role

Procreate is used for:

- sticker artwork
- textures
- brush experiments
- sample clothing designs
- visual asset creation

## Canva role

Optional later for:

- App Store screenshots
- Play Store promo images
- launch assets
