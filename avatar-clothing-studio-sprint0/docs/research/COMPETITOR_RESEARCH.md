# Competitor Research

## Research question

Where is the opportunity if avatar-clothing creator apps already exist?

## Working conclusion

The opportunity is not simply “a clothing maker for mobile”. The stronger positioning is:

**child-friendly + manual-first + privacy-first + ad-free core + safe parent publishing flow**

## Competitor themes observed

### Customuse
Strengths:
- broad creator feature set
- 2D and 3D workflows
- templates and previews
- polished creator ecosystem

Opportunities for differentiation:
- simpler child-first flow
- manual creation more prominent
- less cognitive load
- no requirement to start through AI
- fewer account / subscription barriers in the core experience

### Maker-style clothing apps
Common strengths:
- easy access to templates
- quick clothing editing
- mobile-first

Common weaknesses / risks:
- ad-heavy interfaces
- unclear navigation
- external redirects
- inconsistent trust signals
- limited child-specific safety design

## Product gap to test

Can a 7-year-old independently:

1. start a new design
2. change colors
3. draw something
4. undo a mistake
5. preview the result
6. save it

without adult explanation?

If yes, the UX is delivering a meaningful difference.

## Research metrics

- time to first successful edit
- taps to create first design
- taps to preview
- ability to find undo without help
- ability to understand save state
- number of mistaken taps
- number of points where adult help is required

## Research rule

Do not copy competitor screens or interaction patterns one-to-one. Study usability principles and design an independent experience.
