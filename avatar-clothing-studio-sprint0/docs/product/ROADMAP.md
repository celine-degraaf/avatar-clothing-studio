- product vision
- competitor research
- UX principles
- architecture decision
- security baseline
- repository setup
- Figma wireframes

- brush
- eraser
- color selection
- pan / zoom

- clothing template mapping
- avatar-oriented preview

- export

- accessibility pass

- cloud sync
- storage
