# Product Vision

## Problem

Young users who want to create avatar clothing on a phone or tablet often encounter tools that are cluttered, ad-heavy, confusing, redirect to external browsers, or make AI generation the primary workflow.

## Vision

Build a calm, manual-first mobile creation studio that feels approachable to a young user while still being technically reliable enough for real creator workflows.

## Core promise

A child can create an original design without AI, an account, a subscription or leaving the app.

## Primary users

- Young creators roughly 6–12 years old
- Tablet-first users
- Beginners with no design experience

## Secondary users

- Parents / guardians managing external links, publishing and purchases
- Older beginner creators who want a simpler mobile workflow

## Product principles

1. Manual creation first
2. AI optional, never required
3. Create first, account later
4. Local-first by default
5. No ads in the child experience
6. No unexpected external browser redirects
7. Large touch targets and simple navigation
8. Autosave and visible undo
9. Parent / creator actions are separated from child creation
10. No dark patterns

## MVP outcome

A young user can start a clothing project, edit it, preview it, save it locally and export a technically valid file without needing an account or leaving the app.

## Non-goals for MVP

- community feed
- chat or direct messaging
- followers
- public child profiles
- complex 3D modelling
- automated marketplace activity outside supported official APIs
- automatic purchases or Robux transactions
